# ACCESSIBILITY SPECIFICATION - AJA LOGISTICS

## Standards Compliance (WCAG 2.1 AA)
- High contrast color ratios (> 4.5:1) between text and background.
- Semantic HTML tags (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`).
- Keyboard navigability across inputs, buttons, and mobile drawer menu.
- Screen-reader aria attributes on icons and interactive elements.
