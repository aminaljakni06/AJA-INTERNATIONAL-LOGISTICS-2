# 3D SCENE SPECIFICATION - AJA LOGISTICS

## Overview
Defines visual specs for potential 3D interactive vessel, container ship, and truck fleet previews on the hero landing page.

## Lighting & Atmosphere
- **Ambient Light**: Soft maritime blue intensity (0.6).
- **Directional Light**: Golden hour sunlight (intensity 1.2, color `#F59E0B`).
- **Fog**: Exponential ocean fog for horizon blending (`#0F2C59`).
