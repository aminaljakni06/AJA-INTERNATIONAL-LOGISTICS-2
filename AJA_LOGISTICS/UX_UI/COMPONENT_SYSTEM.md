# COMPONENT SYSTEM - AJA LOGISTICS

## Reusable Components
- `Button`: Primary (`#0F2C59`), Secondary (`#E5A93C`), Outline, Ghost, Danger variants with loading spinners.
- `Card`: Bordered container with subtle shadow and rounded corners (`rounded-2xl`).
- `Input` & `Select`: Form controls with built-in label and error validation formatting.
- `Modal`: Accessible overlay dialog with smooth entry animations.
- `Badge`: Status indicators for quote and shipment states.
