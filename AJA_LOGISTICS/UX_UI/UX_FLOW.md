# UX FLOW SPECIFICATION - AJA LOGISTICS

## Key User Journeys
1. **Shipment Tracking Flow**:
   - Visitor enters tracking number (e.g., `AJA-882910-KSA`) on Hero or `/tracking`.
   - Views timeline stage updates (Cargo Received -> Customs Clearance -> Delivered).
   - Can share live tracking link or download official PDF manifest.

2. **Quote Request Flow**:
   - Visitor selects freight type (Sea / Land / Customs / Warehouse).
   - Enters origin, destination, cargo weight, and contact info.
   - Submits request -> Instantly routed to Admin Quotes queue for staff pricing.

3. **Customer AI Consultation**:
   - Customer opens "Aja AI Assistant" in portal.
   - Asks questions regarding Saudi customs regulation, tariff codes, or shipping delays.
